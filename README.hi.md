> क्या आप कभी विदेशी भाषा के शीर्षक समझ न आने के कारण बेहतरीन YouTube वीडियो देखने से चूक गए हैं?  
> क्या आप शब्द-दर-शब्द अनुवाद करने वाले कठोर मशीन अनुवादों से तंग आ चुके हैं, जो इंटरनेट मीम्स, स्लैंग और मुहावरों को बिल्कुल नहीं समझते?  
> क्या मूल शीर्षक के पूरी तरह गायब हो जाने से आपको निराशा होती है, जिससे वास्तविक भाव सीखने का अवसर छूट जाता है?

**YouTube शीर्षक अनुवादक - AI द्विभाषी शीर्षक** इसी समस्या के समाधान के लिए बनाया गया है! YouTube के लिए अगली पीढ़ी का Chrome एक्सटेंशन: **अनुवाद मूल शीर्षक के स्थान पर प्रमुखता से दिखाई देता है, जबकि मूल शीर्षक नीचे छोटे आकार में सुरक्षित रहता है**। आधुनिक बड़े भाषा मॉडल (LLM) की मदद से यह स्लैंग, लहजे और क्लिकबेट शीर्षकों को स्वाभाविक रूप से अनुवादित करता है और स्वचालित रूप से श्रेणी टैग भी लगाता है। बिना किसी API Key के भी तुरंत काम करता है!

## 🌟 मुख्य विशेषताएं

- 🎯 **सटीक द्विभाषी डिस्प्ले**: अनुवाद प्रमुखता से मुख्य शीर्षक के रूप में दिखाई देता है और मूल शीर्षक नीचे बना रहता है। बिना माउस घुमाए एक नज़र में वीडियो का विषय समझें और संदर्भ में प्रामाणिक भाषा सीखें।
- 🧠 **संदर्भ-सचेत AI अनुवाद (मीम्स और स्लैंग की गहरी समझ)**: शब्द-दर-शब्द यांत्रिक अनुवाद से छुटकारा। इंटरनेट स्लैंग, सांस्कृतिक मीम्स, संक्षिप्ताक्षरों और YouTube क्लिकबेट शैलियों का सटीक व स्वाभाविक अनुवाद।
- 🏷️ **स्मार्ट वीडियो श्रेणी टैग**: अनुवाद करते समय AI वीडियो के क्षेत्र को पहचानकर [टेक], [समाचार], [संगीत], [वित्त], [गेमिंग] जैसे टैग लगाता है, जिससे सही वीडियो चुनना आसान हो जाता है।
- ⚡ **शून्य सेटअप! बिना API Key के भी तैयार**: Chrome 138+ इन-डिवाइस अनुवाद (Chrome Translator) का पूर्ण समर्थन। बिना किसी बाहरी सर्वर या लागत के 100% मुफ़्त, ऑफ़लाइन और सुरक्षित।
- 🌐 **सार्वभौमिक AI और स्थानीय मॉडल समर्थन**: प्रमुख क्लाउड AI प्रदाताओं या किसी भी OpenAI-संगत एंडपॉइंट (Ollama या LM Studio जैसे स्थानीय मॉडल सहित) से आसानी से कनेक्ट करें।
- 🚀 **सुपरफ़ास्ट स्थानीय कैश और वन-क्लिक पुनः प्रयास**: ब्राउज़र कैश दोहराए गए अनुरोधों को रोकता है और टोकन बचाता है। नेटवर्क में क्षणिक समस्या आने पर लाल बैज पर क्लिक करके तुरंत पुनः प्रयास करें।

- **वन-क्लिक पुनः प्रयास**: विफल शीर्षक पर लाल संकेतक दिखाई देता है; दोबारा अनुवाद करने के लिए बस एक बार क्लिक करें।
- **DeepSeek V4 फ़िक्स**: V4 मॉडल के लिए thinking मोड बंद कर दिया गया है ताकि टोकन सीमा समाप्त होने से JSON कटने की समस्या न हो।
- पॉपअप में कैश साफ़ करने का बटन (गणना के साथ), सहेजी गई Key वाले कार्ड पर हरा बिंदु, और परीक्षण के समय तुरंत नमूना अनुवाद देखने की सुविधा।
- 12 नई स्थानीयकरण भाषाएं जोड़ी गईं, जिससे कुल 14 भाषाएं समर्थित हैं।

सेटिंग्स पैनल खोलने के लिए ब्राउज़र टूलबार में एक्सटेंशन आइकन पर क्लिक करें:

![सेटिंग्स विंडो](screenshots/v8.0.1/config-ui.png)

### 1. बुनियादी उपयोग (बिना API Key के)
यदि कोई Key कॉन्फ़िगर नहीं है, तो Chrome 138+ का इन-डिवाइस अनुवाद अपने आप सक्रिय हो जाता है। बस YouTube खोलें और तुरंत द्विभाषी शीर्षक देखें!

### 2. उन्नत AI सेटिंग्स (मीम्स समझ + श्रेणी टैग सक्रिय करें)
प्राकृतिक अनुवाद और स्मार्ट श्रेणी टैग प्राप्त करने के लिए:
1. **Translate titles into**: अपनी लक्षित भाषा चुनें (12 भाषाएं समर्थित);
2. **Choose AI provider**: पसंदीदा AI प्रदाता चुनें और अपनी API Key दर्ज करें;
3. **Save settings** पर क्लिक करें और YouTube पेज को रीफ़्रेश करें।

<details>
<summary><b>Q2: क्या पेज रीफ़्रेश करने पर अतिरिक्त API टोकन खर्च होंगे?</b></summary>

## 💻 डेवलपर गाइड

```bash
# रिपॉजिटरी क्लोन करें
git clone https://github.com/GaryGaryyy/YouTube-AI-Title-Translator.git
cd YouTube-AI-Title-Translator

# सभी यूनिट टेस्ट चलाएं (Node.js 18+ इन-बिल्ट टेस्ट रनर, शून्य बाहरी निर्भरता)
```
