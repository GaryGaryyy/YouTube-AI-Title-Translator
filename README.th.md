> คุณเคยพลาดคลิปดีๆ บน YouTube เพราะอ่านชื่อคลิปภาษาต่างประเทศไม่ออกบ้างไหม?  
> เบื่อกับการแปลแบบเครื่องจักรทื่อๆ ที่แปลตรงตัวจนไม่เข้าใจมุกตลก สแลง และคำย่อบนอินเทอร์เน็ตใช่หรือไม่?  
> รู้สึกหงุดหงิดที่เครื่องมือแปลทั่วไปแทนที่ชื่อคลิปเดิมจนหมด ทำให้ไม่มีโอกาสเทียบและเรียนรู้ภาษาที่แท้จริงใช่ไหม?

**เครื่องมือแปลชื่อคลิป YouTube - ชื่อคลิปสองภาษาด้วย AI** ถูกสร้างขึ้นเพื่อแก้ปัญหานี้โดยเฉพาะ! ส่วนขยาย Chrome ยุคใหม่สำหรับ YouTube: **ข้อความแปลจะแสดงแทนที่ชื่อคลิปอย่างชัดเจน โดยยังคงชื่อคลิปต้นฉบับไว้ด้านล่างในขนาดกะทัดรัด** ขับเคลื่อนด้วยโมเดลภาษาขนาดใหญ่ (LLM) เข้าใจสแลง น้ำเสียง และพาดหัวคลิกเบตได้อย่างเป็นธรรมชาติ พร้อมติดป้ายกำกับหมวดหมู่วิดีโอให้อัตโนมัติ ใช้งานได้ทันทีโดยไม่ต้องมี API Key!

## 🌟 จุดเด่นสำคัญ

- 🎯 **การแสดงผลสองภาษาแบบไร้รอยต่อ**: แสดงผลคำแปลเป็นชื่อเรื่องหลักที่โดดเด่น และคงชื่อเรื่องเดิมไว้ข้างล่างขนาดกะทัดรัด กวาดสายตาดูฟีดได้ทันทีโดยไม่ต้องวางเมาส์เหนือข้อความ เข้าใจเนื้อหาได้รวดเร็วพร้อมเรียนรู้คำศัพท์จริง
- 🧠 **การแปลตามบริบทด้วย AI (เข้าใจมุกและสแลง)**: บอกลาการแปลคำต่อคำที่แข็งทื่อ เข้าใจสแลงอินเทอร์เน็ต มุกตลกทางวัฒนธรรม คำย่อ และสำนวนล่อเป้าสไตล์ YouTube ได้อย่างแม่นยำและเป็นธรรมชาติ
- 🏷️ **ป้ายกำกับหมวดหมู่อัจฉริยะ**: ในขณะแปล AI จะวิเคราะห์หมวดหมู่ของวิดีโอและติดป้ายกำกับ เช่น [เทคโนโลยี], [ข่าว], [ดนตรี], [การเงิน], [เกม] ช่วยให้คุณเลือกดูวิดีโอได้อย่างแม่นยำ
- ⚡ **ไม่ต้องตั้งค่า! ใช้งานได้แม้ไม่มี API Key**: รองรับการแปลในตัวเครื่องของ Chrome 138+ (Chrome Translator) ใช้งานได้ฟรี ออฟไลน์ ปลอดภัย โดยไม่ต้องเชื่อมต่อเซิร์ฟเวอร์ภายนอก
- 🌐 **รองรับ AI ชั้นนำและโมเดลในเครื่องอย่างอิสระ**: เชื่อมต่อกับผู้ให้บริการ AI ยอดนิยมบนคลาวด์ หรือ Endpoint ใดๆ ที่เข้ากันได้กับมาตรฐาน OpenAI (รวมถึงโมเดลในเครื่อง เช่น Ollama หรือ LM Studio)
- 🚀 **แคชในเครื่องที่รวดเร็วและลองใหม่ได้ในคลิกเดียว**: แคชแบบถาวรในเบราว์เซอร์ช่วยป้องกันคำขอซ้ำและประหยัดโควตา หากเกิดข้อผิดพลาดจากเครือข่าย เพียงคลิกที่ป้ายสถานะสีแดงเพื่อลองแปลใหม่ได้ทันที

## 📌 อัปเดตล่าสุด (v8.0.3)

- **ใช้งานได้โดยไม่ต้องมี API Key**: เมื่อไม่ได้กำหนดค่า Key ระบบจะสลับไปใช้การแปลในอุปกรณ์ของ Chrome 138+ โดยอัตโนมัติ เพื่อให้เริ่มต้นได้ฟรีทันที
- **คลิกเพื่อลองแปลใหม่**: ชื่อคลิปที่แปลไม่สำเร็จจะแสดงป้ายสีแดง คลิกหนึ่งครั้งเพื่อสั่งแปลใหม่ได้ทันที
- **แก้ไขปัญหากับ DeepSeek V4**: ปิดโหมด thinking สำหรับโมเดล V4 เพื่อป้องกันการกินโควตาโทเคนจน JSON ขาดตอน
- ป๊อปอัปเพิ่มปุ่มล้างแคช (พร้อมแสดงจำนวนรายการ), แสดงจุดสีเขียวบนการ์ดที่บันทึก Key แล้ว และแสดงตัวอย่างการแปลทันทีเมื่อทดสอบการเชื่อมต่อ
- เพิ่มภาษาการแปลใหม่ 12 ภาษา รวมเป็น 14 ภาษาในส่วนติดต่อผู้ใช้

## 🛠️ การใช้งานและการตั้งค่า

คลิกที่ไอคอนของส่วนขยายบนแถบเครื่องมือเพื่อเปิดแผงควบคุม:

![หน้าต่างการตั้งค่า](screenshots/v8.0.1/config-ui.png)

### 1. การใช้งานพื้นฐาน (ไม่ต้องใช้ API Key)
หากไม่ได้ระบุ Key ส่วนขยายจะเรียกใช้การแปลในอุปกรณ์ของ Chrome 138+ โดยอัตโนมัติ เพียงเปิด YouTube ก็จะเห็นชื่อคลิปสองภาษาได้ทันที!

### 2. การตั้งค่า AI ขั้นสูง (เปิดใช้การแปลสแลง + ป้ายหมวดหมู่)
หากต้องการสัมผัสการแปลที่ลื่นไหลพร้อมติดป้ายกำกับอัจฉริยะ:
1. **Translate titles into**: เลือกภาษาปลายทาง (รองรับ 12 ภาษา);
2. **Choose AI provider**: เลือกผู้ให้บริการที่ต้องการและวาง API Key;
3. คลิก **Save settings** และรีเฟรชหน้า YouTube

### 🔌 การเชื่อมต่อ Custom Endpoint ที่เข้ากันได้กับ OpenAI
เลือก **Custom** เพื่อเชื่อมต่อไปยังบริการใดๆ ที่ใช้มาตรฐาน OpenAI Chat Completions:
- **API Endpoint**: URL แบบเต็ม (เช่น `http://localhost:11434/v1/chat/completions` หรือ OpenRouter);
- **Model name**: รหัสโมเดลที่ต้องการเรียกใช้ (เช่น `llama3.3`, `qwen2.5`);
- **API Key**: คีย์ของผู้ให้บริการ (สำหรับโมเดลในเครื่องที่ไม่มีการยืนยันตัวตน สามารถใส่ข้อความใดก็ได้)

## 🌍 ภาษาที่รองรับ

- **ภาษาปลายทาง (12 ภาษา)**: ไทย, อังกฤษ, จีนตัวย่อ/ตัวเต็ม, ญี่ปุ่น, เกาหลี, สเปน, ฝรั่งเศส, เยอรมัน, โปรตุเกส, อินโดนีเซีย, เวียดนาม
- **ภาษาของอินเทอร์เฟซ (14 ภาษา)**: ไทย, อังกฤษ, จีน, ญี่ปุ่น, เกาหลี, สเปน, ฝรั่งเศส, รัสเซีย, อาหรับ, ฮินดี ฯลฯ
- **การตรวจจับภาษาต้นฉบับอัตโนมัติ**: ตรวจจับภาษาของชื่อคลิปได้แทบทุกภาษาทั่วโลก และข้ามคลิปที่เป็นภาษาปลายทางอยู่แล้วโดยอัตโนมัติ

## 🔒 ความเป็นส่วนตัวและความปลอดภัย

- **ไม่มีการเก็บข้อมูล**: เราไม่ติดตามประวัติการท่องเว็บและไม่เก็บข้อมูลส่วนบุคคลใดๆ
- **จัดเก็บในเครื่อง 100%**: API Key การตั้งค่า และแคชจะถูกบันทึกไว้ใน `chrome.storage.local` บนเบราว์เซอร์ของคุณเท่านั้น
- **ไม่มีเซิร์ฟเวอร์ตัวกลาง**: คำขอจะถูกส่งตรงไปยัง AI ที่คุณเลือก หรือประมวลผลภายในเครื่องของคุณเอง

```bash

# รันการทดสอบทั้งหมด (Node.js 18+ ตัวทดสอบในตัว ไม่มี Dependency ภายนอก)
```
