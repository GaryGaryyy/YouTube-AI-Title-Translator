> Pernahkah Anda melewatkan video YouTube yang luar biasa hanya karena judul berbahasa asing sulit dipahami?  
> Bosan dengan terjemahan mesin kaku kata demi kata yang sama sekali tidak paham meme internet, bahasa gaul, dan singkatan?  
> Frustrasi ketika alat terjemahan menimpa judul asli sepenuhnya sehingga Anda tidak bisa membandingkan dan belajar ungkapan autentik?

**Penerjemah Judul YouTube - Judul Bilingual Berbasis AI** diciptakan tepat untuk mengatasi masalah ini! Ekstensi Chrome generasi baru untuk YouTube: **terjemahan menggantikan judul utama di tempatnya secara jelas, sementara judul asli tetap dipertahankan di bawahnya dalam ukuran ringkas**. Didukung kecerdasan model bahasa besar (LLM), ekstensi ini memahami bahasa gaul, nada bicara, dan gaya judul clickbait, serta menambahkan label kategori otomatis. Dan bekerja langsung tanpa memerlukan API Key apa pun!

---

## 🌟 Keunggulan Utama

- 🎯 **Tampilan Bilingual yang Mulus**: Teks terjemahan muncul sebagai judul utama dan judul asli tetap ada di bawahnya. Jelajahi beranda tanpa perlu mengarahkan kursor, pahami topik seketika sambil mempelajari ekspresi bahasa asli secara kontekstual.
- 🧠 **Terjemahan AI Berbasis Konteks (Paham Meme & Bahasa Gaul)**: Tinggalkan terjemahan harfiah yang kaku. AI mengenali bahasa gaul internet, referensi budaya, singkatan, dan gaya clickbait khas YouTube dengan luwes dan alami.
- 🏷️ **Label Topik Video Pintar**: Saat menerjemahkan, AI menganalisis kategori video dan melampirkan label seperti [Teknologi], [Berita], [Musik], [Keuangan], atau [Game], membantu Anda memilih video tanpa buang waktu.
- ⚡ **Tanpa Pengaturan Rumit! Berfungsi Tanpa Kunci API**: Mendukung terjemahan langsung di perangkat bawaan Chrome 138+ (Chrome Translator). Berjalan 100% gratis, offline, dan menjaga privasi tanpa perlu mengunggah data.
- 🌐 **Dukungan Universal AI & Model Lokal**: Terhubung langsung dengan berbagai penyedia AI cloud terkemuka atau endpoint kustom yang kompatibel dengan standar OpenAI (termasuk model lokal melalui Ollama atau LM Studio).
- 🚀 **Cache Lokal Cepat & Coba Lagi Sekali Klik**: Cache permanen di peramban mencegah permintaan berulang dan menghemat kuota token. Jika terjadi gangguan jaringan sesaat, cukup klik lencana merah untuk mencoba kembali seketika.

## 📌 Pembaruan Terbaru (v8.0.3)

- **Bisa Digunakan Tanpa Kunci API**: Jika tidak ada kunci yang dikonfigurasi, sistem otomatis beralih ke terjemahan bawaan perangkat Chrome 138+ tanpa biaya awal.
- **Coba Lagi Sekali Klik**: Judul yang gagal menampilkan indikator merah; klik sekali untuk mencoba menerjemahkan ulang.
- **Perbaikan Mode Berpikir DeepSeek V4**: Menonaktifkan mode thinking pada model V4 untuk mencegah habisnya batas token yang dapat memotong hasil JSON.
- Popup baru dengan tombol hapus cache (disertai hitungan entri), titik hijau pada kartu dengan kunci tersimpan, dan pratinjau terjemahan langsung saat pengujian.
- Menambahkan 12 bahasa baru, sehingga antarmuka kini mendukung total 14 bahasa.

## 🚀 Mulai Cepat

### Cara 1: Pasang melalui Chrome Web Store (Direkomendasikan)
👉 [Pasang langsung dari Chrome Web Store](https://chromewebstore.google.com/detail/bhajnflcikmidmdalnjhknillnkaojhk)

### Cara 2: Muat Kode Sumber di Mode Pengembang
1. Unduh file rilis ZIP terbaru dari [GitHub Releases](https://github.com/GaryGaryyy/YouTube-AI-Title-Translator/releases) lalu ekstrak;
2. Buka `chrome://extensions/` di Chrome dan aktifkan **"Mode pengembang (Developer mode)"** di sudut kanan atas;
3. Klik **"Muat yang belum dibongkar (Load unpacked)"** di sudut kiri atas dan pilih folder hasil ekstraksi.

## 🛠️ Penggunaan & Pengaturan

Klik ikon ekstensi di bilah alat peramban untuk membuka panel konfigurasi:

![Panel Pengaturan](screenshots/v8.0.1/config-ui.png)

### 1. Penggunaan Dasar (Tanpa Kunci API)
Bila tidak ada API Key yang disimpan, terjemahan bawaan perangkat Chrome 138+ akan aktif secara otomatis. Cukup buka YouTube dan judul bilingual akan langsung terlihat!

### 2. Pengaturan AI Tingkat Lanjut (Terjemahan Gaul + Label Kategori)
Untuk menikmati terjemahan yang lebih luwes dan klasifikasi otomatis:
1. **Translate titles into**: Pilih bahasa tujuan (tersedia 12 bahasa);
2. **Choose AI provider**: Pilih penyedia AI yang Anda inginkan dan tempelkan API Key;
3. Klik **Save settings** lalu muat ulang halaman YouTube Anda.

### 🔌 Endpoint Kustom Kompatibel OpenAI
Pilih **Custom** untuk menghubungkan layanan apa pun yang mematuhi format OpenAI Chat Completions:
- **API Endpoint**: URL endpoint lengkap (mis. `http://localhost:11434/v1/chat/completions` atau OpenRouter);
- **Model name**: ID model yang akan dipanggil (mis. `llama3.3`, `qwen2.5`);
- **API Key**: Kunci API penyedia (dapat diisi sembarang untuk model lokal tanpa autentikasi).

- **Nol Pengumpulan Data**: Kami tidak memantau aktivitas penjelajahan dan tidak mengumpulkan informasi pribadi apa pun.

## ❓ Pertanyaan yang Sering Diajukan (FAQ)

<details>
<summary><b>Q1: Apakah ekstensi ini gratis digunakan?</b></summary>
Ya, ekstensi ini sepenuhnya gratis dan bersumber terbuka di bawah lisensi MIT. Fitur terjemahan bawaan Chrome juga 100% gratis. Bila Anda memakai API cloud eksternal, biaya token ditagihkan langsung oleh masing-masing penyedia sesuai ketentuan mereka.
</details>

<details>
<summary><b>Q2: Apakah memuat ulang halaman akan menghabiskan kuota token lagi?</b></summary>
Tidak. Ekstensi memiliki sistem cache lokal permanen. Judul yang sudah pernah diterjemahkan akan langsung dimuat dari penyimpanan lokal tanpa perlu permintaan jaringan ulang.
</details>

<details>
<summary><b>Q3: Bagaimana jika terjemahan gagal karena masalah jaringan?</b></summary>
Lencana merah penanda kesalahan akan muncul di samping judul. Cukup klik pada lencana tersebut untuk mencoba menerjemahkan ulang seketika.
</details>
