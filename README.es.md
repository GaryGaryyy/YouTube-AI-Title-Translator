> ¿Alguna vez te has perdido excelentes videos de YouTube porque los títulos en otros idiomas eran difíciles de entender?  
> ¿Harto de traducciones automáticas rígidas y literales que no entienden memes, jerga ni modismos de internet?  
> ¿Frustrado cuando las herramientas reemplazan por completo el título original, impidiéndote comparar y aprender expresiones auténticas?

**Traductor de Títulos de YouTube - Títulos Bilingües con IA** ¡nació precisamente para solucionar esto! Una extensión de última generación para Chrome diseñada específicamente para YouTube: **la traducción reemplaza al título de forma destacada, mientras que el título original se conserva debajo en tamaño compacto**. Impulsado por modelos de lenguaje avanzados (LLM), no solo traduce con precisión el contexto, tono y expresiones coloquiales, sino que también asigna etiquetas temáticas automáticas. ¡Y funciona al instante sin necesidad de ninguna API Key!

---

## 🌟 Aspectos Destacados

- 🎯 **Visualización Bilingüe Integrada**: La traducción se muestra de forma destacada y el título original se mantiene debajo. Explora tus recomendaciones con fluidez sin pasar el cursor, captando el tema al instante y aprendiendo expresiones reales en contexto.
- 🧠 **Traducción Contextual con IA (Entiende Memes y Jerga)**: Olvídate de la traducción mecánica palabra por palabra. Comprende a fondo la jerga de internet, referencias culturales, modismos, abreviaturas y el estilo exagerado propio de YouTube.
- 🏷️ **Etiquetas Temáticas Inteligentes**: Al traducir, la IA detecta la categoría del video y añade etiquetas como [Tecnología], [Noticias], [Música], [Finanzas] o [Videojuegos], permitiéndote elegir videos con rapidez.
- ⚡ **¡Cero Configuración! Funciona sin API Key**: Compatible con la traducción local integrada en Chrome 138+ (Chrome Translator). Funciona directamente desde el navegador de forma 100% gratuita, privada y sin conexión.
- 🌐 **Compatibilidad Universal con IA y Modelos Locales**: Conéctate a los principales proveedores de IA en la nube o a cualquier endpoint compatible con la API de OpenAI (incluidos modelos locales como Ollama o LM Studio).
- 🚀 **Caché Local Ultrarrápido y Reintento con un Clic**: La caché persistente en el navegador evita peticiones repetidas y ahorra tokens. Si ocurre un fallo de red puntual, haz clic en la etiqueta roja para reintentar al instante.

## 📌 Novedades Recientes (v8.0.3)

- **Funciona sin API Key**: si no se configura ninguna clave, recurre automáticamente a la traducción local de Chrome 138+, permitiendo usarla de inmediato a coste cero.
- **Reintento con un clic**: los títulos no traducidos muestran un indicador rojo; haz clic una vez para volver a traducir.
- **Corrección del formato en DeepSeek V4**: se desactivó el modo thinking en los modelos V4 para evitar que el razonamiento agotara los tokens y truncara el JSON.
- El panel emergente añade un botón para vaciar la caché (con contador), las tarjetas con clave guardada muestran un punto verde y el botón de prueba muestra una traducción de ejemplo.
- Se agregaron 12 nuevos idiomas de localización, alcanzando un total de 14 idiomas en la interfaz.

## 🚀 Inicio Rápido

### Opción 1: Instalar desde Chrome Web Store (Recomendado)
👉 [Instalar directamente desde Chrome Web Store](https://chromewebstore.google.com/detail/bhajnflcikmidmdalnjhknillnkaojhk)

### Opción 2: Cargar código fuente en Modo Desarrollador
1. Descarga el archivo ZIP de la versión más reciente en [GitHub Releases](https://github.com/GaryGaryyy/YouTube-AI-Title-Translator/releases) y descomprímelo.
2. Abre `chrome://extensions/` en Chrome y activa el **"Modo de desarrollador"** en la esquina superior derecha.
3. Haz clic en **"Cargar descomprimida"** y selecciona la carpeta descomprimida.

## 🛠️ Uso y Configuración

Haz clic en el icono de la extensión en la barra de herramientas para abrir el panel:

![Panel de configuración](screenshots/v8.0.1/config-ui.png)

### 1. Uso Básico (Sin Necesidad de API Key)
Si no configuras ninguna clave, la extensión activa de forma automática la traducción en el dispositivo de Chrome 138+. ¡Abre YouTube y verás los títulos bilingües de inmediato!

### 2. Configuración Avanzada de IA (Modo Memes + Etiquetas)
Para disfrutar de traducciones con matices culturales y clasificación inteligente:
1. **Translate titles into**: Elige el idioma de destino (12 idiomas disponibles);
2. **Choose AI provider**: Selecciona tu proveedor preferido y pega tu API Key;
3. Haz clic en **Save settings** y actualiza la página de YouTube.

## ❓ Preguntas Frecuentes (FAQ)

<details>
<summary><b>Q1: ¿Es gratuita esta extensión?</b></summary>
Sí, la extensión es totalmente gratuita y de código abierto bajo licencia MIT. La traducción integrada en el navegador es 100% gratuita. Si usas APIs de IA en la nube, se aplicarán las tarifas de consumo de cada proveedor.
</details>

<details>
<summary><b>Q2: ¿Recargar la página gasta más tokens de mi API?</b></summary>
No. La extensión incluye una caché local persistente. Una vez traducido un título, se carga al instante desde el navegador sin repetir peticiones a la red.
</details>

<details>
<summary><b>Q3: ¿Qué ocurre si falla la traducción por un problema de red?</b></summary>
Aparecerá un distintivo rojo de error junto al título. Simplemente haz clic en él para reintentar la traducción de inmediato.
</details>

## 💻 Guía para Desarrolladores

```bash
# Clonar el repositorio
git clone https://github.com/GaryGaryyy/YouTube-AI-Title-Translator.git
cd YouTube-AI-Title-Translator

# Ejecutar las pruebas unitarias (Node.js 18+, sin dependencias externas)
npm test
```

- **Stack Tecnológico**: Chrome Extension Manifest V3 (Content Script + Background Service Worker), HTML5/ES6+/CSS3 nativo, Chrome Storage Local API.
- **Sin Paso de Compilación**: Arquitectura nativa sin necesidad de Webpack ni Vite. Basta con recargar la extensión en `chrome://extensions/` para probar cambios al instante.
